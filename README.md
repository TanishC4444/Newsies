# Newsies

A Python news-briefing utility for collecting and formatting current-news summaries.

## Files

- `newsbrief.py` — main application
- `test.py` — development/testing script

## Usage

Review the configuration in the scripts, install their Python dependencies, then run:

```bash
python newsbrief.py
```

## Notes

This project may access third-party news sources. Respect source terms and rate limits, and avoid committing generated content or credentials.
