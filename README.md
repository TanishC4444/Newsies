# Newsies

A Python utility for collecting and formatting current-news summaries.

## Overview

Newsies provides a lightweight workflow for gathering news and producing formatted briefs. The repository is intentionally small, with `newsbrief.py` as the main application entry point.

## Features

- Current-news collection
- News-brief formatting
- Simple local execution
- Development/testing script

## Prerequisites

- Python 3
- Dependencies required by the scripts

## Installation

```bash
git clone https://github.com/TanishC4444/Newsies.git
cd Newsies
```

Install the Python packages imported by the application, then run the brief generator.

## Quick Start

```bash
python newsbrief.py
```

Review the configuration in the scripts before running against external sources.

## Responsible Use

Respect third-party news-source terms and rate limits. Avoid committing credentials or large generated datasets.
